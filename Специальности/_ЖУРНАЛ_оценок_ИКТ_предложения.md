# Предложения: система оценивания и журнал учёта оценок по модулю ИКТ

**Модуль:** «Применение ИКТ и цифровых технологий» (ООМ 2), 96 ч, 39 занятий, форма контроля — **зачёт**, 3 семестр.
**Специальности:** РПО (4S06130103) и ТИС (4S06130105) — правила и модель общие, журнал ведётся отдельно на каждую учебную группу.
**Статус:** УТВЕРЖДЕНО и СОБРАНО. Решения педсовета/зам. директора: 100-балльная буквенная система (A–F); веса 40/20/15/25; оценки раздельно (тест + практика); собраны Excel-помощник и бланк для обоих курсов. Файлы:
- `РПО_Разработка_ПО/Журнал_оценок_ИКТ_РПО.xlsx` и `ТИС_Техник_инф_систем/Журнал_оценок_ИКТ_ТИС.xlsx` — рабочий помощник с авто-расчётом зачёта (проверен: расчёт верный);
- `..._/Бланк_Журнал_учета_ИКТ_<курс>.xlsx` — печатный бланк по форме Приложения 14.

**Обновление (одно-листовой журнал по парам/датам):** `Журнал_оценок_ИКТ_<курс>_1лист.xlsx` — весь журнал на одном листе «Ведомость оценок», столбцы = **учебные пары** (1 дата = 2 ч = 1 пара, всего **48 пар**; занятия по 4–6 ч дробятся на 2–3 пары). Для каждой пары: строка 2 — № занятия, строка 3 — ТИП (Т/П/Пр/С), строка 4 — ДАТА (заполняется). Зачёт считается по типам через AVERAGEIF с весами 40/20/15/25. СРС — отдельным блоком по РО. Совпадает с датовой логикой официальной формы. Старые версии (по занятиям, многолистовая) оставлены.

## 1. Нормативная основа

| Документ | Что определяет |
|---|---|
| Приказ МОН РК № 125 от 18.03.2008 (рег. № 5191, ред. приказом МП РК № 98 от 30.04.2025) | Типовые правила текущего контроля, промежуточной и итоговой аттестации для ТиПО — **как оценивать** |
| Приказ МП РК № 263 от 17.08.2023 (рег. № 33330, ред. № 98 от 30.04.2025) | Формы строгой отчётности; **Приложение 14 «Журнал учёта теоретического обучения»** — **форма журнала** |

**Ключевые нормы для нас (из № 5191, глава по ТиПО):**
1. Оценка знаний — по **цифровой 5-балльной** системе (5/4/3/2) **или** по **100-балльной буквенной** (A–F с цифровым эквивалентом по 4-балльной шкале). Организация выбирает (п.3).
2. Формы, порядок и периодичность **текущего контроля** организация определяет **самостоятельно** (п.4); формы определяет педагог с учётом содержания материала.
3. **Зачёт** по дисциплине/модулю выставляется **на основе оценок текущего контроля с дифференцированными оценками/баллами** (п.8).
4. Отдельного «рубежного контроля» (школьные СОР/СОЧ) для ТиПО нет — только текущий контроль + промежуточная аттестация (зачёт/экзамен).

**Вывод для ИКТ:** у модуля нет экзамена — только **дифференцированный зачёт**. Значит итог модуля целиком складывается из **накопленного текущего оценивания**. Это удобно ложится на нашу структуру (тесты + практические задания + СРС + защита).

## 2. Что именно оцениваем (весь наш материал)

Мы сделали для каждого из 39 занятий комплект файлов. Привязка к видам оценивания:

| Наш материал | Что это | Вид оценивания | Идёт в зачёт |
|---|---|---|---|
| `urok` (теория) | объяснение темы | формативное (работа на занятии, самопроверка) | косвенно |
| `test.gift` | тест по занятию | суммативное — знания | да |
| `zadanie.html` | практическое задание «сделай руками» (вариант по журналу) **+ устная защита** | суммативное — умения | да (главный вес) |
| `upr.md` | упражнения + тема СРС (эссе/отчёт) | СРС | да |
| Занятие **38** мини-проект + **39** защита | итоговая работа модуля | суммативное — комплексно | да (повышенный вес) |

Принцип **AI-устойчивости** (заложен в наших заданиях: вариант по номеру в журнале + устная защита): практические задания и проект засчитываются **только с устной защитой/демонстрацией**. Письменная работа без защиты — неполный балл. Это прямо соответствует нашему примечанию в тематическом плане «приоритет — устная защита».

## 3. Рекомендуемая модель оценивания (накопительная)

Оценка за модуль (зачёт) = взвешенная сумма компонентов текущего контроля:

| Компонент | Что входит | Вес |
|---|---|---|
| **Практические задания** | `zadanie` по занятиям (сделай руками) + устная защита | **40 %** |
| **Тесты** | `test.gift` по занятиям / по РО | **20 %** |
| **СРС** | задания `upr.md` (эссе, отчёты, памятки) | **15 %** |
| **Итоговый проект** | занятие 38 (мини-проект) + 39 (защита) | **25 %** |
| | **Итого** | **100 %** |

Итоговый процент → буква/традиционная оценка по шкале раздела 1 → в графу «Зачёт» и «Итоговая оценка» журнала.

**По результатам обучения (РО):** три РО модуля (2.1, 2.2, 2.3) можно оценивать блоками — средняя по занятиям каждого РО, чтобы видеть, где студент проседает. Это не обязательно нормой, но удобно и наглядно.

**Рейтинг допуска к зачёту** (п.7 правил ведения журнала): среднеарифметическая текущих оценок к концу семестра — по нему решается допуск.

## 4. Структура журнала (по официальной форме, Приложение 14)

Официальная форма «Журнал учёта теоретического обучения» состоит из:

1. **Обложка:** учебная группа, курс, специальность, квалификация, учебный год.
2. **Содержание (оглавление):** № · индекс модуля · наименование дисциплины/модуля · ФИО педагога · страницы.
3. **Левая сторона «Учёт посещаемости и успеваемости»:** № · ФИО студента · столбцы дат занятий (оценка или «н» — отсутствие) · дата занятия · кол-во часов · **критерии оценки / тема занятия** · подпись педагога. Оценка за контрольную/практическую ставится **в день проведения**.
4. **«Итоги учебно-воспитательной работы»:** по дисциплине/модулю — 1-й семестр · 2-й семестр · **рейтинг допуска** · зачёт · экзамен · **итоговая оценка**; строки «часов по плану» и «фактически дано»; блок «Пропущено часов».
5. **Замечания и предложения по ведению** + правила ведения (9 пунктов): документ строгой отчётности, на одну группу на год, синяя ручка, «н» для отсутствия, контроль зам. руководителя.

**Важно:** официальный бланк — бумажный/печатный документ строгой отчётности. Его форму менять нельзя. Но мы можем сделать **рабочий электронный помощник** (Excel), который считает баллы по нашей модели и из которого педагог переносит итоги в официальный журнал.

## 5. Что предлагаю сделать (рабочий журнал-помощник, Excel)

Электронная книга `Журнал_оценок_ИКТ_<группа>.xlsx` с листами:

1. **«Список группы»** — ФИО, № по журналу (для вариантов заданий).
2. **«Текущие оценки»** — студенты × 39 занятий: по каждому занятию колонки «Тест», «Практика (с защитой)»; отметка «н» для пропусков; автоматический %.
3. **«СРС»** — сдача заданий upr по темам.
4. **«Итоги/Зачёт»** — автоматический расчёт по весам (40/20/15/25) → % → буква и 5-балльная оценка → «зачёт/незачёт»; рейтинг допуска.
5. **«Шкала»** — справочная таблица перевода (A–F, %, 5-балльная), формулы ссылаются на неё.
6. **«Инструкция»** — как вести, привязка к нормам № 5191 и № 33330.

Плюс, при желании, **шаблон официального бланка** (Приложение 14) в отдельном файле для распечатки — заполняется из Excel-помощника.

## 6. Решения, которые нужны от вас (зам. директора / педсовет)

1. **Система оценки:** 100-балльная буквенная (A–F) или классическая 5-балльная? (норма допускает обе; буквенная информативнее и «университетская», 5-балльная привычнее).
2. **Веса компонентов:** принять предложенные 40/20/15/25 или свои?
3. **Гранулярность:** одна оценка за занятие (композит тест+практика) или раздельно тест и практика по каждому занятию?
4. **Что делаем:** только Excel-помощник; или Excel-помощник + шаблон официального бланка Приложения 14; для одного курса или сразу для обоих (РПО и ТИС)?

После ваших ответов соберу сам журнал (Excel) с готовыми формулами и, при необходимости, бланк.
