# Применять библиотеки Pandas и NumPy (загрузка, очистка, анализ)

## Практическая ситуация

Тебе скинули файл с тысячей строк журнала мониторинга серверов и просят к завтрашнему дню: среднюю загрузку CPU, число замеров с перегрузкой и список серверов с загрузкой CPU выше 90%. Считать это вручную циклами `for` с `if` и `append` можно, но долго и легко ошибиться — одна опечатка, и весь отчёт неверный.

В реальной работе так не делают. Подключают готовые библиотеки: **NumPy** для быстрых расчётов над числами и **Pandas** для таблиц. С ними одна строка заменяет целый цикл, а отчёт собирается за минуты, а не за вечер.

- создавать NumPy-массив и считать по нему `mean()`, `sum()`;
- представлять таблицу как DataFrame и обращаться к столбцу;

## Почему это важно

Без библиотек обработка данных превращается в длинные циклы, где легко допустить ошибку и которые медленно работают на больших объёмах. NumPy и Pandas — это базовый инструмент любого, кто работает с данными: аналитика, отчёты, подготовка данных для машинного обучения.

Связь с профессией: техник информационных систем постоянно достаёт данные из базы, файла или лога и считает по ним показатели — например, средний чек по заказам, число заявок в техподдержку за неделю, рост загрузки сервера. Знание Pandas и NumPy — это то, что в вакансиях по сопровождению ИС пишут как «обязательно», а не «будет плюсом». Эти же навыки — фундамент для анализа данных и ML (ПМ 5).

## Главное понятие

> **DataFrame** — главный объект Pandas: таблица с именованными столбцами и строками, к каждому столбцу которой можно обратиться по имени и сразу посчитать по нему показатели.

Проще: DataFrame — это «Excel внутри кода». Ты обращаешься к столбцу по имени (`df["cpu"]`), и он ведёт себя как список чисел, но с готовыми методами расчёта.

## NumPy: массивы чисел

**NumPy** — библиотека для работы с массивами чисел. Массив похож на список, но операции над ним считаются быстро и сразу над всеми элементами:

```python
import numpy as np
otvety = np.array([1500, 2000, 1800])
print(otvety.mean())   # 1766.67 — среднее
print(otvety.sum())    # 5300
print(otvety * 2)      # [3000 4000 3600] — умножили все сразу
```

NumPy — внешняя библиотека, её нет в Python по умолчанию: один раз её ставят в терминале командой `pip install numpy`, а строка `import numpy as np` подключает её в программу (и даёт короткое имя `np`). То же и для Pandas ниже — `pip install pandas`.

Не нужен цикл — `mean()`, `sum()`, умножение применяются ко всему массиву сразу. Это называется векторной операцией.

![NumPy: операция применяется ко всем элементам сразу](assets/30_shema-numpy-vektor.svg)

## Pandas: таблицы данных

**Pandas** работает с таблицами. Главный объект — **DataFrame** (таблица со столбцами и строками):

```python
import pandas as pd
data = {"server": ["web-01", "db-01", "cache-01"],
        "cpu":    [45, 90, 95]}
df = pd.DataFrame(data)
print(df["cpu"].mean())   # среднее по столбцу
print(df["cpu"].max())    # максимум
```

Столбец `df["cpu"]` ведёт себя как список чисел, но с готовыми методами: `mean()`, `sum()`, `max()`, `min()`, `count()`.

## Фильтрация строк

Чтобы оставить только строки, удовлетворяющие условию:

```python
zagruzhennye = df[df["cpu"] >= 90]
print(zagruzhennye)
```

Запись `df[df["cpu"] >= 90]` с двумя скобками на первый взгляд похожа на магию. На самом деле здесь два действия, вложенные друг в друга. Разберём их по шагам на нашей маленькой таблице (три сервера с загрузкой CPU 45, 90, 95).

**Шаг 1. Внутреннее `df["cpu"] >= 90` — строим маску.** Мы берём весь столбец загрузки и сравниваем каждое значение с 90. Pandas проверяет условие для каждой строки и возвращает не одно «да/нет», а целый столбец из `True` и `False` — по одному значению на строку. Его называют **маской**:

```python
print(df["cpu"] >= 90)
# 0    False   ← 45 не >= 90
# 1     True   ← 90 >= 90
# 2     True   ← 95 >= 90
```

**Шаг 2. Внешнее `df[ ... ]` — фильтруем по маске.** Теперь мы подставляем эту маску внутрь квадратных скобок самого `df`. Pandas проходит по строкам и оставляет только те, напротив которых в маске стоит `True`, а строки с `False` выбрасывает. Остаются серверы «db-01» (90) и «cache-01» (95), а «web-01» (45) отсеивается.

Другими словами: сначала условие превращает столбец в набор «галочек» `True`/`False`, а потом `df[...]` по этим галочкам выбирает нужные строки. Читай эту конструкцию всегда в два шага — изнутри наружу: сначала маска, потом фильтрация.

Одна строка вместо цикла с `if` и `append`. Это и есть сила Pandas: меньше кода, понятнее результат, меньше шансов ошибиться.

### Мини-кейс

В таблице 1000 замеров загрузки серверов со столбцом `cpu`. Нужно: средняя загрузка и число замеров с перегрузкой (CPU выше 90).

```python
srednyaya = df["cpu"].mean()
peregruz  = len(df[df["cpu"] > 90])
```

Две строки вместо длинного цикла. Вернёмся к ситуации из начала урока — задача «на вечер» решается за пару минут.

## Разбор типичной ошибки

**Ошибка.** Обратиться к столбцу с другим регистром: `df["Cpu"]`, когда столбец называется `cpu`.

**Почему это ошибка.** Имена столбцов в Pandas чувствительны к регистру. `"Cpu"` и `"cpu"` — разные имена, Pandas такого столбца не находит и выдаёт `KeyError`. Похожая беда — забыть `import pandas as pd` или `import numpy as np`: тогда Python не знает имён и выдаёт `NameError`.

**Как правильно.** Делай импорты в начале файла и проверяй точные имена столбцов через `df.columns` — копируй имя оттуда, а не пиши по памяти.
