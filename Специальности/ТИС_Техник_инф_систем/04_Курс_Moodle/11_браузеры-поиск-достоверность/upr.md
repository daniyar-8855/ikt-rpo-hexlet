# Упражнения. Занятие 11. Браузеры, поиск и оценка достоверности

> Формат — поиск и оценка источников. Критерии приёмки под каждым заданием.

## Упражнение 1. Улучши запрос
(а) Студент ищет «не работает программа». Перепиши запрос точно для ситуации: ошибка `ModuleNotFoundError: No module named 'pandas'` в Python.
(б) Инфраструктурный вариант: на рабочей станции — `DNS server not responding`, интернет не открывается. Перепиши слабый запрос «не работает интернет» в точный.

**Критерий приёмки:** (а) запрос содержит текст ошибки + Python/pandas; (б) запрос содержит точную фразу `"DNS server not responding"` + windows/сеть; в обоих убрана вода.

## Упражнение 2. Подбери оператор поиска
Каким оператором: (а) найти точную фразу; (б) искать только на stackoverflow.com; (в) исключить рекламу?

**Критерий приёмки:** (а) `"фраза"`; (б) `site:stackoverflow.com`; (в) `-реклама`.

## Упражнение 3. Оцени источник
Два источника по одной теме: официальная документация (2025) и пост на форуме без автора и даты с громким заголовком. Какой надёжнее и почему (минимум 3 признака)?

**Критерий приёмки:** документация надёжнее; признаки — авторство, дата, проверяемость, отсутствие «сенсационности».

## Упражнение 4. Найди риск
Студент нашёл готовый код на форуме 2014 года и сразу вставил в проект 2026 года. Какие риски?

**Критерий приёмки:** устаревший API/синтаксис, возможные ошибки/уязвимости, непонимание кода; нужно сверить с документацией.

## Упражнение 5. Проверка факта
ИИ-ассистент уверенно назвал функцию, которой нет в библиотеке. Как ты это обнаружишь и проверишь?

**Критерий приёмки:** сверка с официальной документацией библиотеки; вывод — ИИ мог «галлюцинировать».

## Упражнение 6. Поиск по коду ошибки / строке лога
Дана строка из журнала веб-сервера: `nginx: 502 Bad Gateway upstream timed out`. Как сформулируешь запрос, чтобы найти причину, и на каком сайте будешь искать в первую очередь?

**Критерий приёмки:** точная фраза ошибки в кавычках + `nginx`; поиск в официальной документации/на профильной площадке через `site:`; найденное сверить с документацией.

## Упражнение 7. Оцени инфраструктурный источник
По ошибке подключения к сетевому принтеру нашлись два ответа: статья в базе знаний Microsoft (`learn.microsoft.com`, свежая дата) и видео-«лайфхак» без автора и даты, советующий полностью отключить брандмауэр. Какой источник надёжнее и какой совет опасен?

**Критерий приёмки:** надёжнее статья Microsoft (издатель, дата, проверяемость); совет «отключить брандмауэр» — риск безопасности, отвергнуть.

## СРС (самостоятельная работа, 2 ч)

**Тема:** Подборка источников с оценкой достоверности

Подбери 5 источников по теме и оцени их достоверность по критериям. Используй обезличенные/тестовые данные; если применял ИИ — укажи, для чего именно.

**Критерий приёмки:** для каждого источника оценка по 4 критериям (автор, дата, издатель, проверяемость). Работа сдаётся преподавателю (файл/отчёт) и засчитывается как СРС по теме.
