Задание к занятию 19. Работа с открытыми данными

Вариант — по номеру в журнале (своя тема данных на ~5 человек). № 1–5 → В1 · 6–10 → В2 · 11–15 → В3 · 16–20 → В4 · 21–25 → В5 · 26–30 → В6.

Обязательная часть (до 85 баллов)

  1. Найди на data.egov.kz набор данных по теме своего варианта; укажи название, формат, период, ссылку.
  2. Скачай и опиши структуру: какие колонки/поля, сколько записей.
  3. Сделай 3 вывода для отчёта/сводки (максимум, минимум, динамика показателя и т.п.).
  4. Покажи, как получить эти данные через API: приведи вид GET-запроса и разбери, что придёт в ответе (JSON) — какие ключи и значения.
Продвинутая часть (по желанию, +15 баллов): как смежная задача — построй простой график/дашборд по набору (в таблицах или коде) или реально выгрузи набор через API (GET-запрос, разбор JSON-ответа) и защити результат устно.
