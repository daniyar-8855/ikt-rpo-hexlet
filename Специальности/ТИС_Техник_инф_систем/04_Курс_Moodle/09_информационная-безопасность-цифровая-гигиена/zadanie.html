Задание к занятию 09. Аудит цифровой гигиены

Вариант — по номеру в журнале (свой профиль для аудита на ~5 человек). № 1–5 → В1 · 6–10 → В2 · 11–15 → В3 · 16–20 → В4 · 21–25 → В5 · 26–30 → В6.

Обязательная часть (до 85 баллов)

Ты — техник информационных систем, которому поручили навести цифровую гигиену на рабочем месте (у пользователя/в команде) своего варианта.

  1. Проведи аудит цифровой гигиены персонажа своего варианта: найди минимум 5 проблем.
  2. Для каждой проблемы укажи риск и как исправить.
  3. Составь план защиты: пароли, 2FA, права доступа (принцип минимальных привилегий), резервные копии (3-2-1), приватность, секреты, обновления и патчи.
  4. Отдельно отметь, какие действия нарушают Закон РК «О персональных данных».
Продвинутая часть (+15 баллов): настрой реально (на учебном/тестовом аккаунте) менеджер паролей и 2FA, приложи скриншоты, объясни устно.

Профили для аудита по вариантам

  • В1. Пользователь на рабочем месте: один пароль на все системы, 2FA нет, рабочие файлы только на одном ноутбуке.
  • В2. Коллега-разработчик в команде: ключи API прямо в коде на GitHub, пароли сохранены в браузере на общем ПК.
  • В3. Сотрудник, ведущий соцсети организации: выкладывает скриншоты рабочего экрана с данными пользователей, резервных копий нет.
  • В4. Отдел: общий аккаунт на всех, пароль в рабочем чате, реальные данные клиентов в тестовой базе.
  • В5. Сотрудник: «пароли.txt» на рабочем столе, открытые сессии на общих устройствах, права администратора без надобности.
  • В6. Стажёр: пересылает данные клиентов в публичный чат-бот, не ставит обновления, уносит рабочие файлы на личную флешку.

СРС (самостоятельная работа, 2 ч)

Тема СРС: Аудит личной цифровой безопасности (чек-лист).
Задание: Проведи аудит своей цифровой безопасности по чек-листу (пароли, 2FA, права доступа, обновления и патчи, копии) и отметь, что из этого техник ИС так же проверял бы на обслуживаемом рабочем месте. Используй обезличенные данные; укажи, если применял ИИ.
Критерий приёмки: чек-лист заполнен и намечены 3 улучшения.
